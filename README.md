# Crypto Sentiment Trader Analysis

This project analyzes the relationship between Bitcoin market sentiment and Hyperliquid trader performance.

## Objective

To understand how Fear/Greed market sentiment affects trader profitability, win rate, volume, and trading behavior.

## Project Structure

- data/raw: original datasets
- data/processed: cleaned merged dataset
- notebooks: analysis notebook
- src: reusable Python scripts
- visuals: generated charts
- report: final report

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis

- PnL by sentiment
- Win rate by sentiment
- Volume by sentiment
- Buy vs Sell performance
- Top trader analysis
